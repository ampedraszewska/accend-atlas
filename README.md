# ACCEND Ecosystem Atlas

A directory of organisations within the national ecosystems of ACCEND partners that ACCEND companies can access for piloting, financing, public procurement and more.

ACCEND (ACCelerating EuropeaN Deeptech scale-ups) is funded by the European Union under Horizon Europe. More at https://www.accendhorizon.eu/

This repository only hosts the published page (`index.html`).
